description: "A smarter cd that learns which directories I actually mean."
---

zoxide remembers where I go and ranks it, so jumping back to a project is a fragment of its name instead of a full path. It is initialized in my zshrc and otherwise stays out of the way, which is exactly what a directory jumper should do.
