Keep the tools you need. Leave the rest in a catalog the model can search. It adds two moves. Search tools that are off with `query_tools`. Turn exact tools on or off with `manage_tools`.

Install with `pi install npm:@cyanism/pi-toolbelt` and check `/toolbelt status`. From the keyboard, `/toolbelt tools` stages a live set and `/toolbelt settings` edits the baseline. Install changes nothing until you pick a smaller set, which is the whole point.
